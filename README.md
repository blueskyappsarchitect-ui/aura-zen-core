# Aura Flow Core

"Build the core foundation for 'Aura Flow', a premium ADHD Student Planner.

1. Main Layout: > - Create a full-screen, scrollable vertical view.

Background should be a very soft, calming off-white (#F9FBFF).

2. The Aura Timeline (The Soul of the App): > - A thin, centered vertical line representing a 24-hour day.

Left side of the line: Subtle time markers (e.g., 08:00, 09:00, 10:00).

Right side of the line: Blank space for future task blocks.

3. The 'Live' Pulse: > - Add a horizontal violet line (the 'Now' indicator) that sits on the vertical timeline.

Use a CSS animation to make the line 'pulse' gently, showing exactly where the user is in their day.

4. Branding & Header: > - A fixed header at the top with the name 'Aura Flow' in a clean, elegant sans-serif font (Inter).

Include a 'Calendar' icon and a 'Settings' icon (Lucide-React).

5. Navigation: > - A large, circular '+' button floating at the bottom center.

Give the button a 'glassmorphism' style (frosted glass) with a soft lavender glow.

Focus: High-end minimalism. No clutter. It should feel like a 'Digital Zen Garden' for a student."
